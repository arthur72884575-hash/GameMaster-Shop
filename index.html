Como cadastrar produtos

  1. 1. Envie no chat os dois links: o link original do produto na Amazon e o seu link de afiliado.
  2. 2. Peça para criar a página/card do produto. Os dados técnicos e fotos serão extraídos do link original.
  3. 3. No arquivo index.html, localize a linha const produtos = [].
  4. 4. Adicione o objeto do produto logo abaixo dessa linha, usando o modelo comentado no código.
  5. 5. Salve e atualize a página. O produto aparecerá automaticamente na vitrine.
Nunca inclua preços fixos. Use apenas o link de afiliado no campo linkAfiliado.
